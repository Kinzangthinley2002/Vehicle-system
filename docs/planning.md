# Sprint 2: Project Planning & Requirement Analysis - Vehicle Rental System

## 1. Selected Project Details
* **Project Name**: Vehicle Rental System[cite: 3]
* **Template ID**: T10[cite: 3]
* **Domain**: Transportation & Rental Services[cite: 3]
* **Technology Stack**: MERN Stack (MongoDB, Express.js, React.js, Node.js)[cite: 3]

---

## 2. Problem Statement
Many small vehicle rental businesses rely on manual paper records or disconnected tools to manage bookings and vehicle fleets[cite: 3]. These inefficient processes result in reservation overlaps, poor fleet availability tracking, delayed payments, and unorganized customer management[cite: 3].

---

## 3. Project Objective
To build a secure, scalable, and user-friendly web application that centralizes vehicle management, customer accounts, rental bookings, vehicle returns, and billing workflows[cite: 3].

---

## 4. Stakeholders & User Roles
* **Administrator**: Manages system users, vehicle inventory, rental operations, payments, reports, and system settings[cite: 3].
* **Rental Staff**: Registers customers, creates bookings, processes vehicle returns, conducts inspections, and logs payments[cite: 3].
* **Customer**: Browses inventory, requests vehicle rentals, views personal rental history, and manages profile settings[cite: 3].

---

## 5. Project Scope

### Included Scope
* User registration, login, and role-based access control (JWT)[cite: 3].
* Vehicle inventory CRUD operations and availability tracking[cite: 3].
* Customer record and profile management[cite: 3].
* Rental booking creation, updates, and cancellation workflows[cite: 3].
* Vehicle return logging, inspection processing, and status updates[cite: 3].
* Billing, payment recording, and financial reporting[cite: 3].

### Excluded Scope
* Real-time GPS tracking[cite: 3].
* Live payment gateway processing[cite: 3].
* Automated driving license verification API[cite: 3].
* Vehicle maintenance scheduling[cite: 3].
* Native mobile applications[cite: 3].

---

## 6. Functional Requirements
* **Authentication**: User registration, login, JWT issuance, and role authorization[cite: 3].
* **Vehicle Management**: Add, update, delete, search vehicles, and adjust real-time availability[cite: 3].
* **Customer Management**: Profile management, customer record updates, and activity history[cite: 3].
* **Rental Management**: Booking requests, modifications, cancellations, and status updates[cite: 3].
* **Return Management**: Inspection entry, status reset to available, and completion logging[cite: 3].
* **Payment Management**: Invoice generation, payment receipt logging, and revenue tracking[cite: 3].

---

## 7. Non-Functional Requirements
* **Performance**: Fast search responses and low API transaction latency[cite: 3].
* **Security**: Password encryption using bcrypt, JWT authorization, and input validation[cite: 3].
* **Usability**: Fully responsive layout optimized for desktop and mobile browsers[cite: 3].
* **Maintainability**: Modular code architecture with reusable React components and clear API routes[cite: 3].
